Is AE Tweaks safe to use?

Yes. The download is publicly scanned on VirusTotal, and you can even scan it on VirusTotal yourself: just upload AETweaks.exe at virustotal.com and see the results before running anything. AE Tweaks only changes Windows settings, and it creates a restore point before applying tweaks so every change can be undone.

Is it really free? What's the catch?

It's really free. Every tweak, the crosshair designer and potato graphics are unlocked. There are no paid tiers, no trial timer and no license key.

Do I need to sign up or log in?

No. There's no account, no email and no login. Download it, run it, done.

How do restore points work?

Before tweaks are applied, AE Tweaks creates a Windows System Restore point. If anything feels off, revert from inside the app, or open Windows search, type "Create a restore point", click System Restore and pick the AE Tweaks point.

Tip: make sure System Protection is turned on for your C: drive so Windows can save restore points.

Why does Windows show a SmartScreen warning?

SmartScreen warns about apps that don't have a paid code-signing certificate or haven't been downloaded by enough people yet. It's common for small, independent tools. If you've checked the VirusTotal report, click More info → Run anyway.

Can I get banned for using it?

AE Tweaks changes Windows settings, not your games. It doesn't modify game files, inject into processes or read game memory. The crosshair is a standard on-screen overlay, so check your game's rules on overlays if you play in competitive leagues.

How much FPS will I gain?

It depends on your hardware, your game and how your PC is set up now. PCs with lots of background apps or default power settings usually see the biggest difference. Smoother frame times and lower input delay are often more noticeable than the raw FPS number.

Does it work on Windows 11?

Yes. AE Tweaks supports Windows 10 and Windows 11 (64-bit).

Does the app need to stay open?

Most tweaks are applied once and stay after a restart, so you can close the app. Features like the crosshair overlay only run while you have them turned on.
